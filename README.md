# Devin Zalace

My background in environmental science and GIS brings experience with data, technical documentation, and structured problem-solving.

## Featured Projects

- [Hidden Rolls](https://github.com/DevinZalace/HiddenRolls) — React Native companion app and ESP32-CAM firmware for a camera-equipped tabletop dice tray, with live video, connection recovery, and light controls tested on physical hardware.

- [WorldWake](https://github.com/DevinZalace/WorldWake) — Early-stage FastAPI backend for uploading and validating map images, storing project metadata, and tracking map-generation requests.

- [Plant Program](https://github.com/DevinZalace/Plant-Program) — C++ terminal application for browsing and searching a file-backed catalog of 60 ornamental plants.
